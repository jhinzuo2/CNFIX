WHAT THIS IS
  A third-party DLL that injects into the World of Warcraft 1.12 (build 5875)
  client used by some private/custom servers, to display Chinese player and
  guild NAMES as English in the interface. It hooks client functions in memory.
  It changes displayed names/labels, not the chat messages players type.

  - ALWAYS test on an alt / throwaway character before using on your main.

SAFETY DESIGN (what we did to reduce risk)
  - On load it verifies the client build string and a byte-signature at every
    address it intends to hook. If ANY check fails (e.g. after a client patch
    that moves code), it installs NOTHING and silently does nothing — it will
    not hook a client it doesn't recognize. Result: translation simply stops
    working until updated, rather than crashing your game.
  - Pointer reads are guarded; a vectored exception handler logs faults that
    originate in this DLL (debug builds) for diagnosis.
  - It changes only what is DISPLAYED. Your real character names, the server,
    and your account data are unchanged. Outgoing actions (invite/whisper/etc)
    are translated back to the original name before they reach the server.

PRIVACY

  - Logging is OFF by default. It only writes a log if you create a file named
    "WoWRomanizer.debug" next to the DLL, and then only to that same folder
